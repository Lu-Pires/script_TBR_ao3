This is a fork of serpentineegg's Fictrail userscript, with minor changes so it helps you search your Marked For Later and not your full history. For information on how to install it, please check  [Fictrail's github](http://github.com/serpentineegg/fictrail)


## Privacy

All data processing happens locally in your browser. We don't collect, store, or transmit your data.
